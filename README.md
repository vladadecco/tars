# TARS

Asistent vocal personal în limba română pentru Windows: briefing de dimineață, taskuri, proiecte cu analize strategice, cercetare pe internet. Fereastră pe portret.

- Instalare: `Instaleaza TARS.bat`
- Detalii: `CITESTE-MA.txt`
- Actualizări: TARS verifică singur acest depozit și se actualizează (fișierul `VERSION`).

Nu conține chei sau date personale: acestea stau local, în folderul `date/`, care nu e urcat aici.
